# 📊 Walmart Global Sales & Executive Dashboard

> 🌍 A fully interactive Excel dashboard turning 51,000+ raw sales orders into instant, decision-ready insights.


---

## ✨ Overview

Walmart's global sales data is huge — over **51,000 order records** spanning regions like APAC, EMEA, LATAM, and the US. Scrolling through raw rows tells you nothing. 🌀

This project turns that chaos into a **clean, single-screen executive dashboard** — the kind a manager can glance at for 10 seconds and walk away knowing exactly what's happening across the business. 🎯

---

## 🚀 Features

| 🧩 Feature | 📌 What it does |
|---|---|
| 💰 **KPI Scorecards** | Total Sales, Total Profit, Total Quantity Sold & Total Orders — front and center |
| 🌎 **Global Revenue & Profit Breakdown** | Compares performance across every region at a glance |
| 🚨 **Urgency Cost Analysis** | Reveals how much cost is tied up in Critical / High / Medium / Low priority orders |
| 📦 **Product Demand Matrix** | Ranks sub-categories by sales volume — see what's actually moving |
| 📉 **Profit Margin vs. Discount Leakage** | Tracks where aggressive discounting is quietly eating into margins |
| 🎛️ **Live Slicers** | Filter everything instantly by **Segment**, **Market**, and **Category** — no rebuilding required |

---

## 🛠️ Tech Stack

Built **100% natively in Excel** — no plugins, no external tools:

- 📊 **PivotTables** — for fast, flexible aggregation
- 📈 **PivotCharts** — for visual storytelling
- 🎚️ **Slicers** — for real-time, click-to-filter interactivity
- 🧮 **Formulas** — `SUMIFS`, `COUNTIFS`, `INDEX/MATCH` for custom KPI logic
- 🚫 **Zero VBA / Zero Macros** — kept fully transparent and easy for anyone to open and understand

---

## 🗂️ Dataset

A Walmart-style global sales export containing:

- 📦 `Orders` — the core transaction table (51,000+ rows)
- ↩️ `Returns` — which orders were sent back
- 👥 `People` — regional manager mapping
- 📋 `Problem Statement` — the business questions the dashboard is built to answer

## ⚙️ How to Use

1. 📥 Clone or download this repository
2. 📂 Open `Walmart_Dashboard.xlsx` in Microsoft Excel
3. 🖱️ Head to the **Dashboard** tab
4. 🎚️ Use the **Segment**, **Market**, and **Category** slicers to filter live
5. 📊 Watch every KPI and chart update instantly

---

## 🎯 Key Insight Highlights

- 💸 A significant chunk of cost sits in **Critical**-priority orders — worth investigating fulfillment strategy
- 📉 Certain sub-categories show **margin erosion** directly tied to discount levels
- 🌍 Regional performance varies widely — not all markets contribute equally to profit
